# 首页编辑结构

## 本轮调整

首页顺序为 Hero → 本期重点 → 近期文章 → 开源项目 → 船坞 → 页脚。保留 Hero、全站版心、字体、主题和导航；以真实工作替换技能演示，并移除重复潮汐介绍。技能与动效实验仍保留在船坞，不修改 About 或作品集。

近期文章按原始发布日期排序，展示最新三篇；维护日期不参与排序。不再使用横向滚动画廊，手机单列、平板双列、宽屏三列。文章为空时省略该区块；内容在服务端输出，不依赖入场动画。

## 人工维护本期重点

配置位于 `src/lib/home-editorial.ts`，手动维护项目标识、双语文案、站内入口和图片。不得根据模型 API、文章时间、GitHub stars 或自动摘要推断本期重点。路由不带语言前缀，由现有 `TransitionLink` 处理。

第一期为“让模型榜自己更新”。当前状态为 `pre-release`，明确说明自动更新尚待生产验证；没有可靠图片时采用完整文字版，不用 mock 榜单、旧图或空白占位图冒充结果。这个状态不证明后端已经部署。

生产验收后才能改为 `production-verified`：

1. 记录一次受控刷新及一次生产定时自行触发的运行证据，核对每个来源、候选身份及异常状态。
2. 在配置的 `verification` 中写入定时运行 ID、核验时间和证据路径；该字段用于编辑审计，不额外显示到首页。
3. 将验收后的真实榜单局部截图放入 `public/images/`，填写实际宽高和中英文替代文本；截图中不得包含凭据或内部地址。
4. 根据核验结果更新两种语言的文案，不把部分来源成功写成全部成功，不承诺所有厂商价格自动同步。
5. 同步更新首页测试的发布状态断言，复核手机、桌面、深浅主题和链接。

配置类型要求已验证状态具备截图和证据。截图加载失败时隐藏图片，标题、解释与入口仍然保留；无图片状态不创建图片请求。主内容不调用模型 API，也不依赖 WebGL 或客户端加载，榜单接口故障不会阻断本期重点。

## 交付边界

本轮不新增 CMS、案例文章、互动实验或游戏代码。文案不等于生产验收；提交、推送、部署与定时任务真实运行需独立授权与证据。
