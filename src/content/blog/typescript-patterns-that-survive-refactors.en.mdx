Halfway through a change, the page still opened. That is what made me uneasy.

A crash at least makes a sound. More often the detail view appears with a timeline missing a beat. The feedback button can be pressed, and afterward it is neither success nor failure. An article date renders as 1970 — the pipeline did not fall over; it filled an empty hole with something that looked like a date.

Currents detail pages forced the issue. Upstream sometimes sends a shape I cannot use: a link that is not a link, a number that is a sentence, an event status I have never met. If I draw it anyway, the page stays lit. Lit is the hardest kind of wrong. I made that layer fail on a bad shape and send you to a retry screen. Pretending we finished the story is worse.

The feedback form used to blur the same way. Sending, success, rate-limited, network down — easy to stack on one switch. The label on the button would drift from what was actually happening. I write them as strangers to each other now. Rate-limited is rate-limited. No spinning while we claim we already received you.

Dates in the article files got me once. A day in the header was parsed as a timezone-bearing instant. On screen it slipped forward or back by a day. The build stayed green. The calendar was the liar.

I have grown allergic to combinations that should not be true at the same time. Loading, and also failed, and also still holding the last draft. People cannot read that. The program should not either. If a change can catch it before publish, I want that catch. If it cannot, I at least do not want a quiet, completed-looking page.

This has not made me fond of long names for every little thing. I have lost trust in a certain quiet: nothing is red, and a piece is already hollow.

Some of these show up only when you touch the neighboring piece. Add a new failure and you find the success state still clutching a draft it should have dropped. Add a field and the other end still treats it as optional.

When a page still loads, I pause. Open is not the same as finished. Sometimes the mistake simply has not found the door yet.
