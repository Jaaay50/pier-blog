I set the filters on Currents, refreshed, and they were gone.

Source, score, view — all of it had been there. The page came back as if I had just arrived. I sat with that for a couple of seconds, waiting for a choice that was not going to return.

The back button did the same trick. Leave a story, return to the list, and the pile I had made was already tidied into the default. Like walking back into a room where the lamp is still on and the table has been reset.

For a while I kept that kind of state in the page’s own head. Fine while the tab lived. Close it, share it, refresh it, and only I remembered which stack I had been looking at.

I moved the filters that can be said out loud into the address. A link can be copied. Back returns you to the version with the conditions still on. Refresh stops pretending we are at the beginning. The blog’s topic chips work the same way: the name rides after the question mark and survives a reload.

There is a cost you can feel. Change a filter and the address twitches. Sometimes it feels like turning a page. Sometimes there is a small cough while the data comes back.

Read receipts do not belong there. A necklace of article ids on a shared link is a private scratch sent through the mail. Those stay on this machine.

That hiding place created a different mistake. Hover long enough and the next page would preload. Preload used to mark the story read. I had not opened it. The list already looked as if I had. Now only a real visit writes. Preload can hurry the next page. It does not get to decide what I have seen.

I ask a dull question now: if I close the window, should this still exist? If yes, maybe it belongs in the address. If no, it can live on this laptop, or only for this visit.

The sidebar tucked away, the dark or light skin — same family. They do not need to be shared. They only need to remember how I was sitting last time.

After the filters vanished once, I got picky about a page that “remembers.” Memory is useful. Remembering wrong is worse than a blank slate.
