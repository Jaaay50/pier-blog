# Guestbook coastal assets

`CoastalScene` is a full-bleed landscape plate. Copy, the form, and the note list sit below it — not on the painting.

- Stills: `coast-dawn.webp`, `coast-day.webp`, `coast-dusk.webp`, `coast-night.webp`
- Loops: the same names with `.webm` (locked camera; only the sea band is displaced so the clip can loop)

`prefers-reduced-motion: reduce` hides the videos and keeps the stills.
